# 孔雀翎 · Malachite

> 古龙的大杀器，只出鞘一次。
> AIGC 开源图像工作站 —— 画布 + 你的 AI 集群，不订阅，不闭源。

OSM 开源电影（OPEN SOURCE FILM）厂牌下的开源图像工具。定位不是"另一个 GIMP"，
而是 **画布引擎 × ComfyUI 生态**：图层/蒙版/选区/PSD 互通是地基，
生成填充、AI 扩展、风格迁移全部走现成 ComfyUI 工作流——
本地集群跑日常，云端（RunningHub 等）跑大活，同一份 workflow JSON 两边通用。

## 为什么做这个

- Photoshop 的 AI 功能（生成填充/扩展/神经滤镜）是订阅收费最狠的部分，
  而这恰是开源 AI 生态最不缺的。
- 本机推理集群 + ComfyUI + 自训 LoRA/风格库都是现成资产，
  图像工作站 = 给它们一个手。
- OSM 体系从"看电影"扩到"做图"，同一个账号池。

## 架构（MVP）

```
┌─────────────────────────────────────────────┐
│  画布引擎（Web 先行，Electron 壳复用）        │
│  图层 / 蒙版 / 选区 / 变换 / PSD 导入导出     │
├─────────────────────────────────────────────┤
│  AI 桥（ComfyUI client 薄层）                │
│  后端地址一行切换：                           │
│    日常 → http://127.0.0.1:8188（本机集群）   │
│    大活 → https://runninghub.ai/proxy/<key>  │
├─────────────────────────────────────────────┤
│  工作流市场（RunningHub 现成工作流当"滤镜"）  │
│  OSM 自训 LoRA / 风格库工作流优先            │
└─────────────────────────────────────────────┘
```

- 视频/图像源：Cloudflare R2 + CDN（免出口流量费）
- 部署：Web 版挂 osmaigc.com 统一域（app 子域规划中），Electron 本地版打包经验复用平行电影院
- 合规：对外披露 AI 生成属性（与 Steam 商店 AI 披露同口径）
