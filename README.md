# 孔雀翎 · Malachite

> 古龙的大杀器，只出鞘一次。
> **智能体画布** —— 智能体处理图像美术，人类负责修改与审查。开源，不订阅。

OSM 开源电影（OPEN SOURCE FILM）厂牌下的开源 AIGC 图像工作台。

## 定位（2026-10 拍板）

**智能体画布**：平时由智能体处理各种图像美术（生成/填充/扩画布/风格迁移/修图），
人类在画布上做**修改和审查**。

- 人类是导演，智能体是美术。
- 核心抽象 = **操作流（step timeline）**：智能体的每个动作与人类的每个修改
  是同一条时间线上的可审查步骤——看 diff、接受、打回重做、手动微调。
- "审查"是原生能力，不是事后功能；图层系统服务于操作流，而非反过来。

## 架构（MVP）

```
┌──────────────────────────────────────────────┐
│  智能体层：LLM 规划器                          │
│  任务（自然语言）→ 工作流调用序列               │
├──────────────────────────────────────────────┤
│  执行层：ComfyUI 协议（同一份 workflow JSON）  │
│    日常 → http://127.0.0.1:8188（本机集群）    │
│    大活 → https://runninghub.ai/proxy/<key>   │
├──────────────────────────────────────────────┤
│  画布层（Web）：共享工作台                     │
│  步骤时间线 / 前后对比 / 接受·打回·微调         │
├──────────────────────────────────────────────┤
│  兼容层：PSD 导入导出（psd.js）                │
└──────────────────────────────────────────────┘
```

## 为什么做这个

- PS 的 AI 功能（生成填充/扩展/神经滤镜）是订阅收费最狠的部分，
  而开源 AI 生态最不缺的恰是这些。
- 本机推理集群 + ComfyUI + 自训 LoRA/风格库是现成资产，
  智能体画布 = 给它们一个能被人审查的手。
- OSM 体系从"看电影"扩到"做图"，同一个账号池。
